# GitHub Copilot Evidence Checklist

- [ ] Use Copilot for an actual assigned contribution.
- [ ] Capture a real screenshot showing Copilot and relevant code context.
- [ ] Record the prompt/task and describe the suggestion.
- [ ] Link the resulting repository file, commit or PR.
- [ ] Run relevant tests and record actual results.
- [ ] Complete peer review via the team workflow.

Do not mark this evidence complete until the activity has actually occurred.
