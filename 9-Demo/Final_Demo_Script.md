# Final Demo Script — 2 minutes

Record after Sprint 2 regression tests and release-candidate review. Demonstrate only features that work in the tested commit.

| Time | Action | What to show |
|---|---|---|
| 0–15 s | Launch and built-ins | Prompt, pwd, echo, cd, help |
| 15–35 s | Quoting and external commands | Quoted arguments, ls/date and safe malformed input |
| 35–60 s | Redirection | <, >, >> and resulting file contents |
| 60–85 s | Pipelines | Two-stage and, if implemented/tested, multi-stage pipeline |
| 85–100 s | Background | Prompt returns and background process is eventually reaped |
| 100–112 s | Test evidence | Actual make test and make asan-test results |
| 112–120 s | Closeout | Scope, limitations, deviations and release reference |

Before recording, run a clean build and regression suite. Do not present expected output as observed output. Upload the actual two-minute clip.
